# Metta People – Manual Testing & Test Case Documentation

## Project Overview

This section contains the manual QA test case documentation prepared for the Metta People platform.

The document covers functional workflows, positive and negative test scenarios, UI/UX validation, responsive behaviour, and cross-platform testing across Windows, Android, and iOS.

## Testing Scope

The test case documentation covers the following areas:

### 1. Authentication & Account
- User Sign Up
- Mandatory field validation
- Email and phone number validation
- Password validation and visibility
- Terms of Service and Privacy Policy
- Date of Birth selection

### 2. Landing Page
- Landing page loading and navigation
- Header and hero section
- Explore and booking CTAs
- Language selection
- Search and filter components
- Content sections, images, and footer
- Responsive layout

### 3. Provider Onboarding
- Become a Provider journey
- Provider type selection
- Provider profile and details
- Skills, modalities, and document uploads
- Provider application validation

### 4. Listing Management
- Facilitator listing creation
- 1:1 Session and Workshop listings
- Program listing creation
- Bundled sessions and scheduling
- Merchant physical product listing
- Listing media and details
- Listing editing and publishing

### 5. Search & Listing Discovery
- Search functionality
- Keyword and provider/location search
- Listing filters
- Search results and listing details

### 6. Booking & Checkout
- Customer booking workflows
- Booking modal and checkout
- Quantity and pricing validation
- Payment processing
- Booking status and notifications

### 7. Transaction & Booking Lifecycle
- Successful and failed payments
- Payment timeout handling
- Booking creation and status validation
- Customer and provider notifications
- Related booking and transaction scenarios

## Testing Approach

- Functional Testing
- Positive and Negative Testing
- UI/UX Testing
- Validation Testing
- Responsive Testing
- Cross-Platform Testing
- Regression-Oriented Scenarios
- End-to-End Workflow Validation
